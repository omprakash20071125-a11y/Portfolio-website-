# Om Prakash Gupta — TypeScript Portfolio

The original portfolio has been moved into a Vite + TypeScript project. The HTML structure, CSS design, embedded portrait/resume assets, and existing animation logic are retained. Three.js is now imported as an npm dependency instead of loaded from a CDN.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Main files:
- `index.html` — original page structure and embedded assets
- `src/style.css` — original portfolio styles
- `src/main.ts` — TypeScript interactions and Three.js book animation
